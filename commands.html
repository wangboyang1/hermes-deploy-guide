Terminal & Hermes Command Reference

Everything you need to navigate the terminal and use Hermes like a pro — macOS and Windows

Getting Around — Navigation

CommandWhat It Does
pwdShow your current folder (Print Working Directory)
lsList files and folders in the current directory
ls -laList all files, including hidden ones, with details
cd folder-nameMove into a folder
cd ..Go up one level (to the parent folder)
cd ~Go to your home folder
cd /Go to the root of the filesystem
open .Open current folder in Finder
💡 Pro tip: Press Tab to auto-complete folder and file names. Press ↑ (up arrow) to re-run a previous command.

Working with Files and Folders

CommandWhat It Does
mkdir folder-nameCreate a new folder
touch file.txtCreate an empty file
cp source.txt dest.txtCopy a file
cp -r folder/ backup/Copy a folder and everything inside
mv old.txt new.txtMove or rename a file
rm file.txtDelete a file (permanent — no trash!)
rm -rf folder/Delete a folder and everything inside (careful!)

🚀 Hermes Agent Commands

These work the same on all operating systems. Run them in your terminal after installing Hermes.

Getting Started

hermes
Launch interactive chat mode. Start talking to your agent.
hermes setup
Run the setup wizard to configure your model provider.
→ Choose Ollama, point to localhost:11434
hermes model
Interactive model picker — switch models anytime.
hermes chat -q "…"
Ask a single question and get the answer (no interactive session).
→ hermes chat -q "What is 2+2?"

Configuration

hermes config
View your current configuration.
hermes config edit
Open config.yaml in your default editor.
hermes tools
Enable or disable tools (browser, terminal, file access, etc.).
hermes doctor
Check your setup — finds missing dependencies or config issues.

Sessions

hermes --continue
Resume your most recent session.
hermes sessions list
Show your recent conversation history.
hermes -s skill-name
Start a session with a specific skill pre-loaded.

Gateway (Messaging Apps)

hermes gateway setup
Configure Telegram, Discord, WeChat, and other platforms.
hermes gateway run
Start the gateway to connect Hermes to your messaging apps.
hermes gateway install
Install as a background service (survives reboots).
hermes gateway status
Check whether the gateway is running.

🧠 Best Practices & Pro Tips

Collected from the official Hermes docs — quick wins to get the most out of your agent.

🎯 Be Specific
Vague prompts produce vague results. Include file paths, line numbers, error messages, and expected behavior. One detailed message beats three rounds of clarification.
"Fix the TypeError in api/handlers.py line 47" instead of "fix the code"
📋 Front-Load Context
Paste error tracebacks directly. Mention your OS, Python version, project structure. The agent reads everything — give it the full picture upfront.
📄 Use AGENTS.md
Create an AGENTS.md file in your project root with recurring instructions (coding style, test framework, API endpoints). Hermes reads it automatically every session.
"We use pytest with -n 4. All APIs are at /api/v2."
🛠️ Let It Use Its Tools
Don't micromanage HOW the agent works — tell it WHAT you want. Hermes can read files, run commands, and search code. Trust it to figure out the approach.
💾 Use Persistent Memory
Hermes remembers across sessions. Tell it your preferences once: "Remember I prefer tabs over spaces" or "My timezone is UTC+8". It saves these and applies them forever.
hermes memory status — check what's saved
📚 Load Skills for Complex Tasks
Skills are reusable workflows. For PR reviews, GitHub ops, or code review, load the matching skill for pre-tested procedures and edge case handling.
/skills — browse the skill catalog
🔄 Switch Models Mid-Task
Use a fast model for simple queries and a powerful one for complex work. Switch instantly with /model — no restart needed.
/model → pick any configured provider
⏰ Automate with Cron Jobs
Schedule recurring tasks — daily briefings, PR monitoring, system health checks. Hermes can run on a schedule, deliver results to your messaging app.
hermes cron create "every morning 8am"
🔀 Use Profiles for Isolation
Keep work and personal projects separate with profiles. Each has its own config, skills, memory, and sessions — no cross-contamination.
hermes profile create work
📊 Monitor with /usage
Track token usage and costs. Useful when using cloud API models — know exactly what you're spending.
/usage — show current session stats
